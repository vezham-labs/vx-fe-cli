Lists

Ordered, without paragraphs:

1.  Foo
2.  Bar

Unordered, with paragraphs:

- A list item.
  With multiple paragraphs.
- Bar

You can nest them:

- Abacus
  - answer
- Bubbles
  1.  bunk
  2.  bupkis
      - BELITTLER
  3.  burper
- Cunning

Code Spans

`<code>` spans are delimited by backticks.

You can include literal backticks
like `` `this` ``.
